# 取消角色渐隐与随身合成台

辅助功能 →「取消角色渐隐」为开关，默认关闭：开启时完全关闭角色渐隐，关闭时保持游戏原样。旧版“仅抬头时关闭”设置兼容为开启。

辅助功能 →「随身合成台」默认关闭。开启后，游戏大世界右上角会显示合成台图标，点击即可打开合成界面。关闭开关后移除按钮。当前适配国服、B 服和国际服 7.2；国际服地址与字段依据见 [国际服适配记录](global-72.md)。

## 国服 7.2 地址依据

Build ID `6d85e3141bcd6b508f3e853bab508cc407278eac`。未适配的客户端拒绝调用。

- 角色渐隐：`BGMCJLBBGJF.PGODCGCKIHI(float)`，`0xa0a6c50`，调用前核对指令字节。取消渐隐不依赖镜头方向，不读取或写入角色位置及物理状态。
- 合成台：`OADFBEEGOFD.EJNIGFFNPCC(string,string,Action,GCGEJOPPGAE,BaseInterAction)`，`0xfdba624`。断点确认页面标识为 `SynthesisPage`，先前的 `Synthesis` 不被此分发入口接受。第二字符串为空，回调/实体/交互参数为空。返回值仅表示入口接受请求，不表示服务端合成成功。

已删除自由移动和悬浮面板，以及相关 JNI、实体位置和碰撞/重力修改接口。测试覆盖渐隐开关及旧设置兼容、合成按钮的点击隔离、界面重建、限流和引用清理；合成的实际服务端结果需真机验证。
