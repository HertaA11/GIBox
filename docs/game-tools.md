# 取消角色渐隐与随身合成台（1.0.16）

设置 → 通用 →「取消角色渐隐」：保持原样 / 完全关闭 / 仅抬头时关闭，默认保持原样。用户已实测完全关闭模式在拉近镜头和抬头时保持角色可见；其他模式的条件与回退由宿主测试覆盖。

设置 → 通用 →「随身合成台」：先进入游戏大世界，再切回 App 点击并返回游戏。控制文件计数增加后，在游戏 Tick 中执行一次请求；启动时已有的计数不重放。
