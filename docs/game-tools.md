# 取消角色渐隐与随身合成台（1.0.16）

设置 → 通用 →「取消角色渐隐」为开关，默认关闭：开启时完全关闭角色渐隐，关闭时保持游戏原样。旧版“仅抬头时关闭”设置兼容为开启。

设置 → 通用 →「随身合成台」：先进入游戏大世界，再切回 App 点击并返回游戏。控制文件计数增加后，在游戏 Tick 中执行一次请求；启动时已有的计数不重放。
