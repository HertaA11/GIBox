GIBox 是一个 Android 原神上的 xposed 模块

### 使用方法

1. 主页点击“导入MOD”
2. 在角色页选择mod对应的角色/物品，搜索框可输入 ID 中文名 英文名以及模型名
3. 导入后启用即可生效
