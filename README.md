GIBox 是一个 Android 原神上的 xposed 模块

### 使用方法

1. 打开 GIBox，在默认的「模组管理」页点击「导入 MOD」。
2. 选择 MOD 对应的角色或物品。搜索框支持 ID、中文名、英文名和模型名。
3. 导入后启用即可生效。同一 MOD 只转换一次，国服、B 服和国际服共用启停和款式设置；目录和日志按所选客户端显示。

底栏可切换模组管理、辅助功能、设置和关于页。模组管理右上角的日志按钮可查看运行日志，搜索按钮可查找功能、分类和角色。
